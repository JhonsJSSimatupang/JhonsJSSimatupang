## 👨‍💻 About Me

Halo, saya **Jhons Janner Samuel Simatupang**, mahasiswa **Teknik Komputer, Fakultas Ilmu Komputer, Universitas Brawijaya**. Saya fokus di **Embedded Systems, IoT, dan Hardware Engineering**: menjembatani perangkat keras dan perangkat lunak, dari rangkaian dan firmware mikrokontroler sampai aplikasi web.
